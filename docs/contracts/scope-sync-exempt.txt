# reason. Exemption is for deviations no work on this repo can close, which a
# ratchet cannot express: a ratchet line is a promise to come back, and a
# promise needs an issue that can close. A route the Linode API gates behind
# limited availability is absent from the public OpenAPI spec by upstream
# choice, so the deviation persists until the API publishes it, not until
# someone here fixes something.
#
# The bar: an exemption needs upstream evidence that the deviation is real and
# outside this repo's control, named in the reason. Prefer a baseline line
# whenever the deviation is something a change here could close.
#
# The gate still checks these in the other direction: an exemption whose
# deviation stops being generated (the spec published the route) is reported so
# the line is removed rather than left claiming an absence that ended.
#
