# Scope deviations exempt from the sync-scopes ratchet, one per line with a
# reason. Exemption is for deviations no work on this repo can close, which a
# ratchet cannot express: a ratchet line is a promise to come back, and a
# promise needs an issue that can close.
#
# The bar: an exemption needs upstream evidence that the deviation is real and
# outside this repo's control, named in the reason. Prefer a baseline line
# whenever the deviation is something a change here could close.
#
# The gate still checks these in the other direction: an exemption whose
# deviation stops being generated is reported so the line is removed rather
# than left claiming a disagreement that ended.
#
# The six reserved-ip entries this file used to hold are gone with the drift
# class they suppressed. The proto contract is the route oracle now, so a route
# the public OpenAPI spec has never published is a hole in the spec rather than
# a defect here: sync-scopes names those routes and skips them, and
# verify_route_evidence.py proves offline that a client can build each one.
#
# Format: <deviation>\t<reason>
# NEW entries must also carry the baseline-guard acceptance annotation
# (append: `  # accepted YYYY-MM-DD <reason or tracking-issue URL>`).
