# Generated tools: the tools whose Go factory and handler cmd/toolgen emits
# from the linode.mcp.v1 proto contract instead of a hand-written factory.
# Owner: go/cmd/toolgen, run by `make proto`.
#
# A tool listed here has no hand-written factory: the emitter writes one into
# go/internal/gentools, the server registers it from gentools.Factories(), and
# a second factory for the same tool would stage it twice. A tool not listed
# here is still hand-written in go/internal/tools.
#
# Direction: this list only grows. A tool that has been generated once has a
# contract complete enough to generate it, so taking it back out means the
# contract lost something, which is a regression rather than a choice.
#
# Adding a tool means its *Input message declares everything the emitter reads:
# tool_route, tool_capability, tool_response, tool_description, a
# field_location on every field, and error_message where the tier reports a
# failure in prose. The emitter fails by name when one is missing rather than
# emitting a tool that says less than the hand-written one did.
#
# One tool name per line, blank lines and # comments ignored.
